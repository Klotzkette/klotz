# Paragrafen Tic-Tac-Toe

Ein Tic-Tac-Toe-Spiel mit Paragrafenzeichen (§ vs §§) auf einem 45°-gedrehten Spielfeld. Gebaut mit Python und Pygame.

## Features

- Spieler 1: **§** (einfach)
- Spieler 2: **§§** (doppelt)
- Spielfeld: **45° gedreht** (Rautenform)
- Verfügbar für Windows und macOS
